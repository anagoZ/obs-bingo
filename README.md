# OBS Bingo

**使い方ページ：https://anagoz.github.io/obs-bingo/**

OBSで使うビンゴ番号表示ページです。画面の左側に出た番号・履歴・1〜75の盤面を表示し、右側は透明なのでカメラ（ガラガラ）を下に置いて映せます。

## OBSでの設定

1. ソース追加 →「映像キャプチャデバイス」でカメラを追加し、画面の右側に配置
2. ソース追加 →「ブラウザ」→「ローカルファイル」にチェックして `bingo.html` を選択
3. 幅・高さを配信の解像度と同じ値（1920×1080 / 1280×720 など）にする。どのサイズでも自動で全体が収まります
4. ブラウザソースをカメラより上に置く

## スマホをカメラにする（アプリ不要）

スマホのブラウザで `camera.html` を開くと、スマホのカメラ映像がビンゴ画面の右側の枠に直接映ります。OBSにカメラのソースを追加する必要はありません。

1. ビンゴ画面の設定（歯車ボタン / S キー）を開き、「QRとコードを表示する」を押すとQRコードと8文字の接続コード（例：ab3k-9xqz）が出ます（60秒後・設定を閉じたとき・スマホがつながったときに自動で隠れます）
2. スマホでQRコードを読む（または https://anagoz.github.io/obs-bingo/camera.html を開いてコードを入力）
3. 「カメラ開始」を押してカメラを許可 → 右側の枠に映ります

- つながると、スマホで番号を入力できます。「一覧」（B〜Oの表から番号をタップ）か「テンキー」で選んで、下の「表示」でビンゴ画面に出ます。「取り消し」「リセット」もスマホからできます
- 目のボタンでプレビューを隠せます
- 画面の配置は上の「自動 / 縦 / 横」ボタンで切り替えられます。横向きでは一覧がビンゴ画面と同じ横長になり、75個すべてがスクロールなしで見えます
- スマホとPCは同じWi-Fiにつないでください
- 「スマホの映像に枠の比率を合わせる」がオンだと、縦向き・横向きに合わせて枠が自動で変わります
- 接続コードは保存されるので、次回からはスマホで同じページを開いて「カメラ開始」を押すだけです
- 接続の仲介に PeerJS の無料サーバーを使います（映像はスマホとPCの間で直接やりとりします）
- `camera.html` は https で開く必要があるため、GitHub Pages で公開して使います

### 安全に使うために

- 接続コードを知っている人は誰でもつなげます。QRとコードは配信に映らないよう、配信前に表示してつないでください
- 「ロック」がオンだと、つながっているスマホ以外からの接続を断ります。別のスマホに替えるときは「今のスマホを切断」を押してください
- コードが配信に映ってしまったときは「コードを変える」を押してください（つながっているスマホも切断されます）

## アプリ内抽選（カメラ・ガラガラなし）

設定画面の一番上「右側の表示」を **アプリ内抽選** にすると、右側に画面上のガラガラが出ます。

- 右下の **サイコロボタン**（ガラガラ本体のクリックでもOK）、**Space キー**、またはスマホの **「抽選」** ボタンで回すと、まだ出ていない番号からランダムに1つ出て、そのまま表示されます
- 抽選中にもう一度押しても、二重に出ることはありません
- 「カメラ」に戻すと、今まで通りカメラでガラガラを映せます。出た番号はどちらのモードでも共通です
- スマホは、開始画面のカメラを **「使わない」** にすると、カメラなしで操作だけつなげます

## カメラの解像度（右側の枠）

「対話」画面で **S キー** を押すと設定が開きます。プリセット（16:9 / 4:3 / 1:1 / 3:4 / 9:16）を選ぶか、幅と高さを入力して「適用」すると、右側の枠がその比率になります。枠の外は背景色で隠れます。

設定画面に表示される「位置 X / Y」「幅 × 高さ」を、OBSでカメラを右クリック →「変換」→「変換の編集」に入力すると、カメラが枠にぴったり収まります（バウンディングボックスの種類は「内側の境界に合わせて拡大縮小」）。

URLで `bingo.html?res=1080x1920` のように指定することもできます。

## 操作

ブラウザソースを右クリック →「対話」を開いて操作します。

| キー | 動作 |
| --- | --- |
| 数字 → Enter | 番号を表示 |
| Backspace（入力が空のとき） | 直前の番号を取り消し |
| Esc | 打ちかけの数字をクリア |
| Shift+R を2回 | 全部リセット |
| S | 設定を開く/閉じる |
| Space | 抽選（アプリ内抽選のとき） |

ショートカットを忘れても、左パネル右下の **歯車ボタン**（設定）と **矢印ボタン**（リセット、2回押しで確定）で操作できます。設定画面にもショートカット一覧が出ます。
| 盤面の数字をクリック | 出した/消したを切り替え |

入力した番号は保存されるので、OBSを再読み込みしても消えません。

普通のブラウザで `bingo.html?cam=1` を開くと、右側にPCのカメラを映して見た目を確認できます。
