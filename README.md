# BINGO — ブラウザで使えるビンゴ番号表示

**ビンゴ画面：https://anagoz.github.io/obs-bingo/bingo.html**
**使い方ページ：https://anagoz.github.io/obs-bingo/**

ブラウザで開くだけで使える、ビンゴの番号表示です。画面の左側に出た番号・履歴・1〜75の盤面を、右側に画面上のガラガラかカメラの映像を表示します。テレビやプロジェクター、オンラインの画面共有、OBSでの配信にも使えます。

## 使い方

1. PCのブラウザでビンゴ画面を開く。左下の全画面ボタンか **F** キーで全画面にできます
2. 左下の歯車ボタン（**S** キー）で設定を開き、「右側の表示」を選ぶ
   - **アプリ内抽選**（初めて開いたときはこちら）：右下のサイコロボタンか **Space** キーで回すと、まだ出ていない番号からランダムに1つ出て表示されます
   - **カメラ**：本物のガラガラをスマホやPCのカメラで映し、出た番号を入力します
3. 番号を出す（PCのキー操作、またはスマホから）

出た番号はブラウザに保存されるので、閉じたり再読み込みしたりしても消えません。

## スマホをカメラ・リモコンにする（アプリ不要）

1. 設定画面で「QRとコードを表示する」を押すと、QRコードと8文字の接続コード（例：ab3k-9xqz）が出ます（60秒後・設定を閉じたとき・スマホがつながったときに自動で隠れます）
2. スマホでQRコードを読む（または https://anagoz.github.io/obs-bingo/camera.html を開いてコードを入力）
3. 「カメラ開始」を押してカメラを許可 → 右側の枠にスマホの映像が映ります

- カメラを使わないときは、スマホの開始画面でカメラを「使わない」にして「接続する」を押すと、操作だけつなげます
- つながると、スマホから「🎲 抽選」（アプリ内抽選のとき）、番号入力（「一覧」か「テンキー」で選んで「表示」）、取り消し・リセットができます
- 画面の配置は「自動 / 縦 / 横」ボタンで切り替えられます。横向きでは一覧がビンゴ画面と同じ横長になります
- スマホとPCは同じWi-Fiにつないでください
- 接続の仲介に PeerJS の無料サーバーを使います（映像はスマホとPCの間で直接やりとりします）

PCのカメラを使うときは、設定画面の「このPCのカメラを使う」を押します（URL に `?cam=1` を付けても使えます）。

### 安全に使うために

- 接続コードを知っている人は誰でもつなげます。QRとコードは、画面共有や配信に映らないように表示してください
- 「ロック」がオンだと、つながっているスマホ以外からの接続を断ります。別のスマホに替えるときは「今のスマホを切断」を押してください
- コードが映ってしまったときは「コードを変える」を押してください（つながっているスマホも切断されます）

## PCでの操作

| キー | 動作 |
| --- | --- |
| Space | 抽選（アプリ内抽選のとき） |
| 数字 → Enter | 番号を表示 |
| Backspace（入力が空のとき） | 直前の番号を取り消し |
| Esc | 打ちかけの数字をクリア |
| Shift+R を2回 | 全部リセット |
| S | 設定を開く/閉じる |
| F | 全画面（ブラウザのとき） |
| 盤面の数字をクリック | 出した/消したを切り替え |

ショートカットを忘れても、左下のボタン（全画面・設定・リセット）で操作できます。設定画面にもショートカット一覧が出ます。

## OBSで使う

1. OBSのソース追加 →「ブラウザ」を選び、「ローカルファイル」はチェックせずに、URLに `https://anagoz.github.io/obs-bingo/bingo.html` を入れる
2. 幅・高さを配信の解像度と同じ値（1920×1080 など）にする
3. 操作は、ブラウザソースを右クリック →「対話」を開いて行います

OBSでは「カメラ」モードの枠の中が透明になるので、OBSの「映像キャプチャデバイス」をブラウザソースの下に置いて映すこともできます。設定画面の「カメラの解像度」でプリセット（16:9 / 4:3 / 1:1 / 3:4 / 9:16）か幅と高さを選ぶと、枠がその比率になります。表示される「位置 X / Y」「幅 × 高さ」を、カメラの「変換」→「変換の編集」に入力すると、枠にぴったり収まります（バウンディングボックスの種類は「内側の境界に合わせて拡大縮小」）。URLで `bingo.html?res=1080x1920` のように指定することもできます。
